# meta-hikrobot
Hikrobot SDK and tools meta layer for Bitbake Yocto

This layer based on HikRobot SDK version 3.0.1 (MVS-STD-3.0.1_241128).

SDK support different platforms:
- ARM (64 bit) (aarch64);
- ARM (32 bit) (arm, armhf);
- x86 (64 bit);
- x86 (32 bit).

In current version meta layer support only ARM64 (aarch64) platform and was tested for Rockchip RK3588 ROC-RT3588-RT board with USB3.0 camera connection.
Tested camera - HikRobot mv-cs016-10um.
